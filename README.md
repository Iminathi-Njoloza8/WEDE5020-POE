## Project Overview
I have created a website for a fictional company that mainly focuses on selling fruits and vegetables.
This company is called EcoFresh Grocers, and it was established in 2022 in Eastern Cape, King Williams Town. The company is known for supporting local farmers while offering quality products and excellent customer service.

## Website Goals and Objectives
  - Allow customers to order online.
  - Promote weekly specials and seasonal products.
  - Improve customer satisfaction.
  - Increase monthly sales by 40%.

## Target Audience
  - People who live closer to the location of the shop.
  - Farmers who need a starter.
  - People who are interested in shoping here.

## Key Features and Functionality
  - Fresh grocery products
  - Locally sourced products
  - Home delivery
  - Weekly specials
  - Customer accounts
  - Secure online payments
  - Customer support
  - Product search and categories

## Part 3 Details
Several improvements were made to the EcoFresh Grocers website to enhance its usability, appearance and functionality. HTML was used to organise the content into structured sections and provide appropriate page titles and metadata. CSS was implemented to create a consistent design across the website, while responsive design techniques were used to improve the layout on different screen sizes (MDN Web Docs, 2026a; MDN Web Docs, 2026c).

The Products and Services page was improved by introducing product cards and a CSS Grid layout, allowing products to be displayed in an organised and visually appealing manner. Image sizing was also adjusted using the CSS object-fit property to maintain consistent presentation (MDN Web Docs, 2026d; MDN Web Docs, 2026e). JavaScript was incorporated to support interactive features such as product searching, category filtering and expandable frequently asked questions (MDN Web Docs, 2025b).

The Contact and Enquiry pages were improved by adding labelled form fields and HTML validation attributes. These features help users provide the required information and identify invalid entries. Proper form labels also improve accessibility for people using assistive technologies (MDN Web Docs, 2026f; W3C, n.d.a). An embedded Google Maps display was included to help visitors identify the business location (Google for Developers, 2026).
